LOOPER TEX Premium Catalogue Website
=====================================

Open index.html in a browser (or upload the folder to a static host).
Files: index.html, style.css, app.js, catalogue.json.

Catalogue: 11 categories with 50 style concepts each (550 total).
The product cards currently use original vector garment illustrations.
Hero/about photographs load from Unsplash and require internet access.
These are not approved LOOPER TEX production photographs. Replace them with
your own approved product/model photographs before publishing as actual styles.

Before launch, verify company claims, unit/machine counts, ISO certificate
scope, contact details, and all product specifications. This package is not
published online and has not been submitted to Google for indexing.

Free hosting options can include GitHub Pages or Google Sites (depending on
whether you want to upload this static site as-is; Google Sites does not
directly host a custom HTML folder).
